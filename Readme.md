Описание:
Программа для автоматического парсинга данных с CSFloat и Steam, с базовым ML-модулем для предсказания цен на скины CS2 и удобным графическим интерфейсом.

______________________________________________________________________
Настройка:
Перед запуском нужно заполнить файл .env

1. CSFloat API Key
Зарегистрируйся / войди на csfloat.com

Перейди в Settings → Developer → API Key

Скопируй ключ и вставь в .env:

API_KEY=твой_ключ_здесь

2. Steam Cookie
Нужен для получения истории цен со Steam. Cookies берутся из браузера.

Войди в Steam аккаунт на store.steampowered.com

Открой DevTools → F12 → вкладка Application → Cookies → https://store.steampowered.com

Найди и скопируй следующие значения:

Переменная	Cookie-имя
STEAM_LOGIN_SECURE	steamLoginSecure
STEAM_SESSION_ID	sessionid
STEAM_COUNTRY	steamCountry
Вставь в .env:

text
STEAM_LOGIN_SECURE=значение_из_браузера
STEAM_SESSION_ID=значение_из_браузера
STEAM_COUNTRY=значение_из_браузера
⚠️ Важно: Cookies Steam истекают примерно через 1–3 месяца. Если парсер перестал получать данные Steam — обнови их по той же инструкции.

Настройка Postgres:

Просто скопируй это в .env --

POSTGRES_HOST=postgres
POSTGRES_PORT=5432
POSTGRES_USER=postgres
POSTGRES_PASSWORD=626862
POSTGRES_DB=CSfloat

Как запустить:

1 - Сервер

Установи Docker если его нет https://www.docker.com/products/docker-desktop/
-Запусти startServer.bat
-Дождись полной загрузки (время зависит от скорости интернета)

2 -- Приложение
-Запусти startApp.bat
-Дождись установки зависимостей
-Если появится ошибка, связанная с npm — установи Node.js

ЧТО УМЕЕТ:

-Парсинг двух сайтов — CSFloat и Steam без таймаутов со стороны сайтов. Если таймаут всё же появился — это проблема на стороне сервера, нужно увеличить время ожидания в настройках. Программу можно безопасно держать на сервере до 60 дней

-ML — предсказание цены — базовая модель машинного обучения (LightGBM), которая вычисляет прогнозную цену по накопленным данным. Для нормальной работы обязательно нужно минимум 30 дней данных, рекомендуется 60+

-Графический интерфейс — удобный Electron-интерфейс для просмотра данных, статистики БД и статуса ML-модели
